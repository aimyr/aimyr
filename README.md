# Aimer Koshmambetov

Yonsei University student from Kazakhstan, building software and hardware that make education, assistive technology, and research tools easier to use.

My work combines product development with hands-on engineering: preparing datasets and evaluation pipelines, connecting scientific tools to AI assistants, and turning prototype ideas into usable interfaces.
